診所預約系統：數據庫設計修訂 (SQL-92)

修訂重點： 將「預約人士」與「醫護人員」拆分為獨立實體表。
  • Patient 表： 使用「電話」作為主鍵及登入帳號。
  • Staff 表： 使用「員工編號」作為主鍵及登入帳號。

一、 實體關係圖 (ERD) 與 表結構

1. Patient 表 (預約人士資料)

欄位類型描述備註
PhoneVARCHAR(8)電話號碼Primary Key (PK)
PasswordVARCHAR(255)登入密碼預設為 '0000'
NameVARCHAR(100)姓名
DOBDATE出生日期格式: YYYY-MM-DD
HKIDVARCHAR(10)身份證號範例: A123456(7)

2. Staff 表 (醫護人員資料)

欄位類型描述備註
EmployeeIDVARCHAR(20)員工編號Primary Key (PK)
PasswordVARCHAR(255)登入密碼預設為 '0000'
NameVARCHAR(100)姓名
RoleVARCHAR(10)職位'nurse' / 'doctor'
DoctorRoomVARCHAR(10)診室醫生專用屬性

3. Appointment 表 (預約記錄)

欄位類型描述備註
ApptIDINT預約編號PK, Auto-increment
PatientPhoneVARCHAR(8)病人電話Foreign Key (FK) -> Patient.Phone
ApptDateDATE預約日期
ApptSessionVARCHAR(2)時段'AM' / 'PM'
DoctorNameVARCHAR(100)醫生姓名
QuotaNoINT籌號1-15

二、 按鈕操作與 SQL 語句對照

功能操作與 SQL 語句
預約人士登入
SELECT * FROM Patient WHERE Phone = :phone AND Password = :password;
醫護人員登入
SELECT * FROM Staff WHERE EmployeeID = :empID AND Password = :password;
新預約登記
INSERT INTO Patient (Phone, Password, Name, DOB, HKID) VALUES (:phone, :pw, :name, :dob, :hkid);
提交預約 (檢查籌號)
SELECT COUNT(*) AS Count FROM Appointment WHERE ApptDate = :date AND ApptSession = :session AND DoctorName = :doctor;
醫護查詢 (跨表 Join)
SELECT A.*, P.Name FROM Appointment A JOIN Patient P ON A.PatientPhone = P.Phone WHERE A.ApptDate = :date ORDER BY A.QuotaNo ASC;

DSE ICT SBA 評核建議

  • 實體拆分： 解釋 Patient 與 Staff 分開能落實「最小權限原則」及減少數據冗餘。
  • 資料完整性： 強調 Appointment.PatientPhone 是 Foreign Key，確保不會出現無主預約。
  • 查詢效能： 討論在 ApptDate 欄位建立索引 (Index) 的必要性，以加速每日名單的檢索。
